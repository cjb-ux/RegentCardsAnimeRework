## ✨ What this is

RegentCardsAnimeRework is a card portrait art pack for Regent from Slay the Spire 2. It gives the cards a cute, colorful anime look. Use it if you want a softer visual style while you play.

## 🖼️ What you get

- New card portrait artwork for Regent
- Bright colors with a clean anime style
- A simple setup for Windows users
- Files that are easy to place in the game folder
- Artwork made to fit the card layout

## 💻 System needs

Use this on a Windows PC with:

- Windows 10 or Windows 11
- Enough free space for the art files
- A working copy of Slay the Spire 2
- File access to the game folder
- A basic unzip tool, such as File Explorer or 7-Zip

## 🛠️ If something does not work

If the new portraits do not show up, check these common points:

- The files may be in the wrong folder
- The zip file may not have been extracted
- The game may need a restart
- The file names may have changed
- Another mod may be replacing the same portraits

Try moving the files back to the original folder structure and start the game again. If the art still does not appear, compare the folder names with the files inside the download.

## 📌 File handling tips

Use these habits to keep setup simple:

- Keep a backup of the original portrait files
- Do not rename files unless the project says to
- Put the new files in one folder before copying them
- Remove extra copies if you test more than once
- Save the zip file in case you want to reinstall later

## 🔄 Updating later
